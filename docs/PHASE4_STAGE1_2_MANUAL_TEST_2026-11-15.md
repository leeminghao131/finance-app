# MH Finance App · Stage 1.2 手动验收说明

**阶段命名：Stage 1.2（继 Stage 1.1 后第二次修改）**。后续同阶段修改依次 Stage 1.3、Stage 1.4。此分支从 Stage 1.1 最新可运行 Preview 继承，未合并 main。

**仅限测试环境：** 必须登录 MH Finance Test 的虚构账号，确认页面显示 TEST MODE。不要使用正式账号，也不要导入真实财务流水。尚未完成 Windows、Android、双账号人工验收。

## 01｜财务模拟器：两条可以正负调整的滑块
1. 打开页面左边缘抽屉里的“财务模拟器”，进入“第二步”。
2. 应只有 **每月收入变化（RM）** 和 **每月支出变化（RM）** 两个金额输入框；旧的“每月多赚、每月少花、每月额外多花”三输入框不再出现。
3. 两条滑块中心是 **0**，左侧是负值，右侧是正值。可用滑块、输入框或旁边的 ± 快捷按钮改变正负；所有输入为正常 RM（输入 100 表示 RM100，不是 RM1）。
4. 语义：
   - 收入 **+RM300**：每月多赚 RM300。
   - 收入 **−RM300**：每月少赚 RM300。
   - 支出 **+RM200**：每月多花 RM200。
   - 支出 **−RM200**：每月少花 RM200。
5. 确认计算符合：**每月余额差额 = 收入变化 − 支出变化；N 个月累计差额 = 月差额 × N**。
   - 6 个月，收入 +300、支出 −200 → **+RM3,000**。
   - 6 个月，收入 −300、支出 +200 → **−RM3,000**。
   - 6 个月，收入 +100、支出 +300 → **−RM1,200**。
   - 两者 0 → **RM0** 差额。
6. 打开保存的方案列表。Stage 1 / 1.1 旧版计划例如「多赚 1150、少花 300、额外多花 120.50」，应转换成「收入变化 +1150、支出变化 −179.50」且**预计结果不变**。原方案的 ID、名称、月数仍保留。
7. 允许带两位小数的负数，如 −12.34；超过两位小数的输入应报错，不应保存为有效计划。
8. 点击保存、查看历史计划、刷新页面，检查预设留存在**当前设备当前测试账号**；登录第二测试账号，不能出现其他账号的计划。
9. 以上全部是 Scenario 虚构预测，不能更改实际 Income、Expense、Transfer、Expected Income、Budget 或余额。

## 02｜左侧抽屉增加月度对比与储蓄目标
1. 用 Windows 打开 Dashboard，鼠标悬停左边缘。抽屉应展开四个入口：
   - ✨ 财务回顾 Finance Wrapped
   - 📈 财务模拟器 Finance Simulator
   - 📊 月度财务对比 Month Comparison
   - 🎯 储蓄目标 Savings Goals
2. 首页原来最后两张大型卡片不再常驻，不占据 Dashboard 空间，也不会让其他卡片移动。
3. 点击“月度财务对比”，应弹出原来的**完整月度对比卡片**，不是简化图片。选择任意两个月及跨年月份，收入、支出、净额、柱状图、交换月份、分类对比浮窗均须正常工作。
4. 关闭月度对比，然后点击“储蓄目标”，应弹出原来的**完整储蓄目标卡片**。检查可用储蓄 = 总 Balance − 当前自然月 Budget（结果按现有规则）。新增一个虚构目标，例如「测试旅行 RM5000」，保存成功后刷新再打开；应保留目标。
5. 在储蓄目标浮窗内部继续打开“编辑目标”小浮窗，修改测试目标名称或日期并确认。两个层级的 X / Escape / 滚动操作都要正确；对原始交易、转账和预算没有写入。
6. 测试储蓄目标删除：只删除你专门创建的测试目标，确保真实财务记录没有受到影响。
7. Android 浏览器中点击左侧露出的标签，四个入口应可触控、按下打开完整浮窗、正常滚动和关闭，不能出现画面横向滚动或重叠导致功能不可按。
8. 电脑和 Android 的 Cloud Test 同账号应查看同一储蓄目标；不同测试账号不能看到对方的目标。
9. 完成后确认原来独立的 Finance Wrapped 和 Simulator 仍能打开、关闭、滑动和使用。

## 03｜回归保护
- Income 正常 RM 输入 100 → RM100.00；Cents 输入 2455 → RM24.55。
- Transfer BANK → TNG RM100 后两边余额变化，总 Balance 不变。
- Monthly Budget、Opening Balance、Savings Goals 云端保存与 RLS 完整，不擅自修改历史记录。
- Undo、Recycle Bin Restore、CSV 预览导入和 Excel 导出正常。
- 中文／英文切换，以及刷新后语言保留。
- Preview 中必须出现 TEST MODE；如果显示数据库错误或不受认可环境，立即停止。
- 勿使用正式数据库、真实银行流水或 Production 凭据测试。
