# Finance App

This is a Vite + React + Tailwind finance dashboard.

## Upload to GitHub
Upload every file and folder in this project to your `finance-app` GitHub repository.

## Deploy to Vercel
1. Open Vercel.
2. Add New Project.
3. Import your GitHub `finance-app` repository.
4. Framework preset should be `Vite`.
5. Click Deploy.

## Current data storage
This version stores data in the browser using localStorage. It works on Vercel, but computer and phone data are not synced yet.

After deployment works, Supabase cloud sync can be added.
